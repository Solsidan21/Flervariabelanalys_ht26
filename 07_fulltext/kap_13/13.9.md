# Section 13.9: Taylor's Formula, Taylor Series, and Approximations

*Note: This section corresponds to Chapter 12, Section 12.9 in the 9th edition of Adams' Calculus. The numbering has been updated to Section 13.9 for use in the 10th edition.*

## Introduction

As is the case for functions of one variable, power series representations and their partial sums (Taylor polynomials) can provide an efficient method for determining the behaviour of a smooth function of several variables near a point in its domain. In this section we will look briefly at the extension of Taylor's formula and Taylor series to such functions. We will do this for functions of n variables as it is no more difficult to do this than to treat the special case n = 2.

## Taylor's Formula for Functions of Several Variables

As a starting point, recall Taylor's formula for a function F(t) with continuous derivatives of order up to m + 1 on the interval [0, 1]:

    F(1) = F(0) + F'(0) + F''(0)/(2!) + ... + F^(m)(0)/(m!) + F^(m+1)(ξ)/((m+1)!),

where ξ is some number between 0 and 1. (The last term in the formula is the Lagrange form of the remainder.)

Now suppose that a = (a₁, a₂, ..., aₙ) and h = (h₁, h₂, ..., hₙ) belong to Rⁿ. If f is a function of x ∈ Rⁿ that has continuous partial derivatives of orders up to m + 1 in an open set containing the line segment joining a and a + h, we can apply the above formula to

    F(t) = f(a + th),     (0 ≤ t ≤ 1).

By the Chain Rule we will have

    F'(t) = h₁f_{h₁}(a + th) + h₂f_{h₂}(a + th) + ... + hₙf_{hₙ}(a + th)
          = (h · ∇)f(a + th),

where

    (h · ∇)f(a + th) = (h₁D₁ + h₂D₂ + ... + hₙDₙ)f(x)|_{x=a+th}

and Dⱼ = ∂/∂xⱼ (1 ≤ j ≤ n). Similarly,

    F''(t) = h₁h₁f₁₁(a + th) + h₁h₂f₁₂(a + th) + ... + hₙhₙf_{nn}(a + th)
           = (h · ∇)²f(a + th),

and in general

    F^(j)(t) = (h · ∇)^j f(a + th).

Thus, F(1) = f(a + h), F(0) = f(a), and F^(j)(0) = (h · ∇)^j f(a). The Taylor formula given above thus says that

    f(a + h) = f(a) + (h · ∇)f(a) + (h · ∇)²f(a)/(2!) + ... + (h · ∇)^m f(a)/(m!)
             + (h · ∇)^(m+1) f(a + θh)/((m+1)!)
           = Σ_{j=0}^m [(h · ∇)^j f(a)]/(j!) + R_m(h; θ)
           = P_m(h) + R_m(h; θ).

This is Taylor's formula for f about x = a. P_m(h) is a polynomial of degree m in the components of h. P_m(h) is called the mth degree Taylor polynomial of f about x = a. The term corresponding to j in the summation defining P_m is, if not zero, a polynomial of degree exactly j in the components of h, whose coefficients are jth order partial derivatives of f evaluated at x = a. The remainder term R_m(h; θ) is also a polynomial in the components of h, each of whose terms if not zero has degree exactly m + 1, but its coefficients are (m + 1)st order partial derivatives of f evaluated at an indeterminate point a + θh along the line segment between a and a + h.

Sometimes it is useful to replace the explicit remainder in Taylor's formula with a Big-O term that is bounded by a multiple of |h|^(m+1) as |h| → 0:

    f(a+h) = f(a) + h·∇f(a) + (h · ∇)²f(a)/(2!) + ... + (h · ∇)^m f(a)/(m!) + O(|h|^(m+1)).

If all partial derivatives of f are continuous, and if there exists a positive number r such that whenever |h| < r we have for all θ ∈ [0, 1],

    lim_{m→∞} R_{m+1}(h; θ) = 0,

then we can represent f(a + h) as the sum of the Taylor series

    f(a + h) = Σ_{j=0}^∞ [(h · ∇)^j f(a)]/(j!).

### Remark

An alternative approach is to develop Taylor's formula with directional derivatives. Following Section 13.7, a function g(s) is introduced, where s - s₀ is distance, measured along a line L in direction u, from the point on L corresponding to s = s₀. As in Section 4.10, a Taylor formula for g(s) is

    g(s) = g(s₀) + g'(s₀)(s - s₀) + (1/2!)g''(s₀)(s - s₀)² + ... + (1/m!)g^(m)(s₀)(s - s₀)^m + O(|s - s₀|^(m+1)).

Since d/ds = u · ∇ is the directional derivative operation in direction u, the directional derivative extends to all orders in the Taylor expansion in s. We may choose g(s) = f(a + (s - s₀)u), where (s - s₀)u = h. It follows that |h|ⁿ = |s - s₀|ⁿ and

    g(s) = f(a+h) = f(a) + (h·∇)f(a) + (h · ∇)²f(a)/(2!) + ... + (h · ∇)^m f(a)/(m!) + O(|h|^(m+1))

as above.

## EXAMPLE 1

If f is a function of two variables, x and y, having continuous partial derivatives of order up to 4 in the disk (x - a)² + (y - b)² < r², then for h = (h, k) in R² satisfying h² + k² < r we have

    f(a + h, b + k) = P₃(h, k) + R₃(h, k; θ)

where

    P₃(h, k) = f(a, b) + (hD₁ + kD₂)f(a, b) + (1/2!)(hD₁ + kD₂)²f(a, b)
             + (1/3!)(hD₁ + kD₂)³f(a, b) + R₃(h, k; θ)

           = f(a, b) + hf₁(a, b) + kf₂(a, b)
           + (1/2!)[h²f₁₁(a, b) + 2hkf₁₂(a, b) + k²f₂₂(a, b)]
           + (1/3!)[h³f₁₁₁(a, b) + 3h²kf₁₁₂(a, b) + 3hk²f₁₂₂(a, b) + k³f₂₂₂(a, b)]
           + R₃(h, k; θ),

where R₃(h, k; θ) = (1/4!)(hD₁ + kD₂)⁴f(a + θh, b + θk) = O((h² + k²)²).

Note that since 0 < θ < 1, all the 4th-order partial derivatives of f are bounded on the line segment from (a, b) to (a + h, b + k). This is why the remainder term is O((h² + k²)²).

As for functions of one variable, the Taylor polynomial of degree m provides the "best" nth-degree polynomial approximation to f(x, y) near (a, b). For n = 1 this approximation reduces to the tangent plane approximation

    f(x, y) ≈ f(a, b) + f₁(a, b)(x - a) + f₂(a, b)(y - b).

## EXAMPLE 2

Find a second-degree polynomial approximation to the function f(x, y) = √(x² + y³) near the point (1, 2), and use it to estimate the value of √((1.02)² + (1.97)³).

### Solution

For the second-degree approximation we need the values of the partial derivatives of f up to second order at (1, 2). We have

    f(x, y) = √(x² + y³)                          f(1, 2) = 3
    f₁(x, y) = x/√(x² + y³)                       f₁(1, 2) = 1/3
    f₂(x, y) = 3y²/(2√(x² + y³))                  f₂(1, 2) = 2
    f₁₁(x, y) = y³/(x² + y³)^(3/2)                f₁₁(1, 2) = 8/27
    f₁₂(x, y) = -3xy²/(2(x² + y³)^(3/2))          f₁₂(1, 2) = -2/9
    f₂₂(x, y) = (12x²y + 3y⁴)/(4(x² + y³)^(3/2)) f₂₂(1, 2) = 2/3

Thus,

    f(1 + h, 2 + k) ≈ 3 + (1/3)h + 2k + (1/2!)[8/27 h² + 2(-2/9)hk + 2/3 k²]

or, setting x = 1 + h and y = 2 + k,

    f(x, y) ≈ 3 + (1/3)(x - 1) + 2(y - 2) + (4/27)(x - 1)² - (2/9)(x - 1)(y - 2) + (1/3)(y - 2)².

This is the required second-degree Taylor polynomial for f near (1, 2). Therefore,

    √((1.02)² + (1.97)³) = f(1 + 0.02, 2 - 0.03)
                         ≈ 3 + (1/3)(0.02) + 2(-0.03) + (4/27)(0.02)²
                          - (2/9)(0.02)(-0.03) + (1/3)(-0.03)²
                         ≈ 2.9471593.

(For comparison purposes the true value is 2.9471636... The approximation is accurate to 6 significant figures.)

As observed for functions of one variable, it is not usually necessary to calculate derivatives in order to determine the coefficients in a Taylor series or Taylor polynomial. It is often much easier to perform algebraic manipulations on known series. For instance, the above example could have been done by writing f in the form

    f(1 + h, 2 + k) = √((1 + h)² + (2 + k)³)
                    = √(9 + 2h + h² + 12k + 6k² + k³)
                    = 3√(1 + (2h + h² + 12k + 6k² + k³)/9)

and then applying the binomial expansion

    √(1 + t) = 1 + (1/2)t + (1/2!)(1/2)(-1/2)t² + ...

with t = (2h + h² + 12k + 6k² + k³)/9 to obtain the terms up to second degree in the variables h and k.

## EXAMPLE 3

Find the Taylor polynomial of degree 3 in powers of x and y for the function f(x, y) = e^(x-2y).

### Solution

The required Taylor polynomial will be the Taylor polynomial of degree 3 for e^t evaluated at t = x - 2y:

    P₃(x, y) = 1 + (x - 2y) + (1/2!)(x - 2y)² + (1/3!)(x - 2y)³
             = 1 + x - 2y + (1/2)x² - 2xy + 2y² + (1/6)[x³ - x²y + 2xy² - 2y³].

## Remark

Maple can, of course, be used to compute multivariate Taylor polynomials with its function mtaylor. The function mtaylor takes arguments as follows:

(a) an expression involving the expansion variables
(b) a list whose elements are either variable names or equations of the form variable=value giving the coordinates of the point about which the expansion is calculated.
(c) (optionally) a positive integer m forcing the order of the computed Taylor polynomial to be less than m.

Some examples:

    > mtaylor(cos(x+y^2),[x,y]);
      1 - (1/2)x² - (1/2)y² + (1/24)x⁴ + (1/2)y²x² + (1/6)y²x³

    > mtaylor(cos(x+y^2),[x=Pi,y],5);
      -1 + (1/2)(x - π)² + y²(x - π) - (1/24)(x - π)⁴ + (1/2)y⁴

## Approximating Implicit Functions

In the previous section we saw how to determine whether an equation in several variables could be solved for one of those variables as a function of the others. Even when such a solution is known to exist, it may not be possible to find an exact formula for it. However, if the equation involves only smooth functions, then the solution will have a Taylor series. We can determine at least the first several coefficients in that series and thus obtain a useful approximation to the solution. The following example shows the technique.

## EXAMPLE 4

Show that the equation sin(x + y) = xy + 2x has a solution of the form y = f(x) near x = 0 satisfying f(0) = 0, and find the terms up to fourth degree for the Taylor series for f(x) in powers of x.

### Solution

The given equation can be written in the form F(x, y) = 0, where

    F(x, y) = sin(x + y) - xy - 2x.

Since F(0, 0) = 0 and F₂(0, 0) = cos(0) = 1 ≠ 0, the equation has a solution y = f(x) near x = 0 satisfying f(0) = 0 by the Implicit Function Theorem. It is not possible to calculate f(x) exactly, but it will have a Maclaurin series of the form

    y = f(x) = a₁x + a₂x² + a₃x³ + a₄x⁴ + ...

(There is no constant term because f(0) = 0.) We can substitute this series into the given equation and keep track of terms up to degree 4 in order to calculate the coefficients a₁, a₂, a₃, and a₄. For the left side we use the Maclaurin series for sin to obtain

    sin(x + y) = sin[(1 + a₁)x + a₂x² + a₃x³ + a₄x⁴ + ...]
               = (1 + a₁)x + a₂x² + a₃x³ + a₄x⁴ + ...
               - (1/3!)[(1 + a₁)x + a₂x² + ...]³ + ...
               = (1 + a₁)x + a₂x² + [a₃ - (1/6)(1 + a₁)³]x³
               + [a₄ - (1/6)(1 + a₁)²a₂]x⁴ + ...

The right side is xy + 2x = 2x + a₁x² + a₂x³ + a₃x⁴ + ... Equating coefficients of like powers of x, we obtain

    1 + a₁ = 2              → a₁ = 1
    a₂ = a₁                 → a₂ = 1
    a₃ - (1/6)(1 + a₁)³ = a₂  → a₃ = 7/3
    a₄ - (1/6)(1 + a₁)²a₂ = a₃ → a₄ = 13/3.

Thus,

    y = f(x) = x + x² + (7/3)x³ + (13/3)x⁴ + ...

(We could have obtained more terms in the series by keeping track of higher powers of x in the substitution process.)

### Remark

From the series for f(x) obtained above, we can determine the values of the first four derivatives of f at x = 0. Remember that

    a_k = f^(k)(0)/(k!).

We have, therefore,

    f'(0) = a₁ = 1         f''(0) = 2!a₂ = 2
    f'''(0) = 3!a₃ = 14    f⁽⁴⁾(0) = 4!a₄ = 104.

We could have done the example by first calculating these derivatives by implicit differentiation of the given equation and then determining the series coefficients from them. This would have been a much more difficult way to do it.
