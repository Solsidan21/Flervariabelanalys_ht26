## Section 12.3: Curves and Parametrizations

In this section we will consider curves as geometric objects rather than as paths of moving particles. Everyone has an intuitive idea of what a curve is, but it is difficult to give a formal definition of a curve as a geometric object (i.e., as a certain kind of set of points) without involving the concept of parametric representation. We will avoid this difficulty by continuing to regard a curve in 3-space as the set of points whose positions are given by the position vector function:

    r = r(t) = x(t)i + y(t)j + z(t)k,  a ≤ t ≤ b

However, the parameter t need no longer represent time or any other specific physical quantity.

## EXAMPLE 1

Use t = y to parametrize the part of the line of intersection of the two planes y = 2x - 4 and z = 3x + 1 from (2, 0, 7) to (3, 2, 10).

Solution We need to express all three coordinates of an arbitrary point on the line as functions of t = y. Since y = t, the equation y = 2x - 4 assures us that x = (1/2)(y + 4) = (1/2)(t + 4). Then the equation z = 3x + 1 gives z = (3/2)(t + 4) + 1 = (3/2)t + 7. Since the line segment goes from y = 0 to y = 2, the required parametrization is:

    r = ((t + 4)/2) i + tj + ((3t + 14)/2) k,  0 ≤ t ≤ 2

## EXAMPLE 2

The plane x + y = 1 intersects the paraboloid z = x^2 + y^2 in a parabola. Parametrize the whole parabola using t = x as parameter. Could t = y have been used as the parameter? What about t = z?

Solution From the equations of the two surfaces defining the parabola, we have y = 1 - x = 1 - t, and z = x^2 + y^2 = t^2 + (1 - t)^2 = 1 - 2t + 2t^2. Thus, the required parametrization is:

    r = ti + (1 - t)j + (1 - 2t + 2t^2)k,  -oo < t < oo

We could use t = y instead of t = x as the parameter; in this case the parametrization would be:

    r = (1 - t)i + tj + (1 - 2t + 2t^2)k,  -oo < t < oo

However, if we try to use t = z as the parameter, we would have to solve the system of equations x + y = 1, x^2 + y^2 = t for x and y. This system has two possible solutions, each corresponding to a different half of the parabola starting at the lowest point (1/2, 1/2, 1/2) because there are two points on the parabola at each height z > 1/2. The whole parabola cannot be parametrized using z as the parameter.

### Continuity and Smoothness


[sid 644]

Curves can be very pathological. For instance, there exist continuous curves that pass through every point in a cube. It is difficult to think of such a curve as a one-dimensional object. In order to avoid such strange objects we assume hereafter that the defining function r(t) has a continuous first derivative, dr/dt, which we will continue to call "velocity" and denote by v(t) by analogy with the physical case where t is time. (We also continue to call v(t) = |v(t)| the "speed".) As we will see later, this implies that the curve has an arc length between any two points corresponding to parameter values t₁ and t₂; if t₁ < t₂, this arc length is:

    integral(t₁ to t₂) v(t) dt = integral(t₁ to t₂) |v(t)| dt = integral(t₁ to t₂) |dr/dt| dt

Frequently we will want r(t) to have continuous derivatives of higher order. Whenever needed, we will assume that the "acceleration," a(t) = d^2r/dt^2, and even the third derivative, d^3r/dt^3, are continuous. Of course, most of the curves we encounter in practice have parametrizations with continuous derivatives of all orders.

It must be recalled, however, that no assumptions on the continuity of derivatives of the function r(t) are sufficient to guarantee that the curve r = r(t) is a "smooth" curve. It may fail to be smooth at a point where v = 0. (See Example 1 in Section 12.1.) We will show in the next section that if, besides being continuous, the velocity vector v(t) is never the zero vector, then the curve r = r(t) is smooth in the sense that it has a continuously turning tangent line.

Although we have said that a curve is a set of points given by a parametric equation r = r(t), there is no unique way of representing a given curve parametrically. Just as two cars can travel the same highway at different speeds, stopping and starting at different places, so too can the same curve be defined by different parametrizations; a given curve can have infinitely many different parametrizations.

## EXAMPLE 3

Show that the vector functions:

    r₁(t) = sin t i + cos t j,          (-π/2 ≤ t ≤ π/2)
    r₂(t) = (t - 1) i + sqrt(2t - t^2) j,  (0 ≤ t ≤ 2)
    r₃(t) = sqrt(t^2 - t^4) i + (1 - t^2) j,  (-1 ≤ t ≤ 1)

all represent the same curve. Describe the curve.

Solution All three functions represent points in the xy-plane. The function r₁(t) starts at the point (-1, 0) with position vector r₁(-π/2) = -i and ends at the point (1, 0) with position vector i. It lies in the half of the xy-plane where y ≥ 0 (because cos t ≥ 0 for -π/2 ≤ t ≤ π/2). Finally, all points on the curve are at distance 1 from the origin:

    |r₁(t)| = sqrt((sin t)^2 + (cos t)^2) = 1

Therefore, r₁(t) represents the semicircle y = sqrt(1 - x^2) in the xy-plane traversed from left to right.

The other two functions have the same properties: both graphs lie in y ≥ 0,

    r₂(0) = -i,  r₂(2) = i,  |r₂(t)| = sqrt((t - 1)^2 + 2t - t^2) = 1
    r₃(-1) = -i,  r₃(1) = i,  |r₃(t)| = sqrt(t^2(2 - t^2) + (1 - t^2)^2) = 1

Thus, all three functions represent the same semicircle. Of course, the three parametrizations trace out the curve with different velocities.

### Closed Curves and Simple Closed Curves

The curve r = r(t), (a ≤ t ≤ b), is called a closed curve if r(a) = r(b), that is, if the curve begins and ends at the same point. The curve C is non-self-intersecting if there exists some parametrization r = r(t), (a ≤ t ≤ b), of C that is one-to-one except that the endpoints could be the same:

    r(t₁) = r(t₂)  for a ≤ t₁ < t₂ ≤ b  ÷  t₁ = a and t₂ = b

Such a curve can be closed, but otherwise does not intersect itself; it is then called a simple closed curve. Circles and ellipses are examples of simple closed curves. Every parametrization of a particular curve determines one of two possible orientations corresponding to the direction along the curve in which the parameter is increasing.

[FIGUR 12.9: Exempel på kurvor; C₁ och C₃ är icke-självskärande; C₂ och C₄ skär sig själva; C₁ och C₂ är inte slutna; C₃ och C₄ är slutna; C₃ är en enkel sluten kurva]

All three parametrizations of the semicircle in Example 3 orient the semicircle clockwise as viewed from a point above the xy-plane. This orientation is shown by the arrowheads on the curve. The same semicircle could be given the opposite orientation by, for example, the parametrization:

    r(t) = cos t i + sin t j,  0 ≤ t ≤ π

### Parametrizing the Curve of Intersection of Two Surfaces

Frequently, a curve is specified as the intersection of two surfaces with given Cartesian equations. We may want to represent the curve by parametric equations. There is no unique way to do this, but if one of the given surfaces is a cylinder parallel to a coordinate axis (so its equation is independent of one of the variables), we can begin by parametrizing that surface. The following examples clarify the method.

## EXAMPLE 4

Parametrize the curve of intersection of the plane x + 2y + 4z = 4 and the elliptic cylinder x^2 + 4y^2 = 4.

Solution We begin with the equation x^2 + 4y^2 = 4, which is independent of z. It can be parametrized in many ways; one convenient way is:

    x = 2 cos t,  y = sin t,  (0 ≤ t ≤ 2π)

The equation of the plane can then be solved for z, so that z can be expressed in terms of t:

    z = (1/4)(4 - x - 2y) = 1 - (1/2)(cos t + sin t)

Thus, the given surfaces intersect in the curve:

    r = 2 cos ti + sin tj + (1 - (cos t + sin t)/2) k,  (0 ≤ t ≤ 2π)

[FIGUR 12.10: Skärningen mellan ett snett plan och en elliptisk cylinder]

## EXAMPLE 5

Find a parametric representation of the curve of intersection of the two surfaces:

    x^2 + y + z = 2  and  xy + z = 1

Solution Here, neither given equation is independent of a variable, but we can obtain a third equation representing a surface containing the curve of intersection of the two given surfaces by subtracting the two given equations to eliminate z:

    x^2 + y - xy = 1



This equation is readily parametrized. If, for example, we let x = t, then:

    t^2 + y(1 - t) = 1,  so  y = (1 - t^2)/(1 - t) = 1 + t

Either of the given equations can then be used to express z in terms of t:

    z = 1 - xy = 1 - t(1 + t) = 1 - t - t^2

Thus, a possible parametrization of the curve is:

    r = ti + (1 + t)j + (1 - t - t^2)k

Of course, this answer is not unique. Many other parametrizations can be found for the curve, providing orientations in either direction.

### Arc Length

We now consider how to define and calculate the length of a curve. Let C be a bounded, continuous curve specified by:

    r = r(t),  a ≤ t ≤ b

Subdivide the closed interval [a, b] into n subintervals by points:

    a = t₀ < t₁ < t₂ < ... < tₙ₋₁ < tₙ = b

The points rᵢ = r(tᵢ), (0 ≤ i ≤ n), subdivide C into n arcs. If we use the chord length |rᵢ - rᵢ₋₁| as an approximation to the arc length between rᵢ₋₁ and rᵢ, then the sum:

    sₙ = sum(i=1 to n) |rᵢ - rᵢ₋₁|

approximates the length of C by the length of a polygonal line.

[FIGUR 12.11: En polygonal approximation av en kurva C]

Evidently, any such approximation is less than or equal to the actual length of C. We say that C is rectifiable if there exists a constant K such that sₙ ≤ K for every n and every choice of the points tᵢ. In this case, the completeness axiom of the real number system assures us that there will be a smallest such number K. We call this smallest K the length of C and denote it by s. Let Δtᵢ = tᵢ - tᵢ₋₁ and Δrᵢ = rᵢ - rᵢ₋₁. Then sₙ can be written in the form:

    sₙ = sum(i=1 to n) (|Δrᵢ|/Δtᵢ) Δtᵢ

If r(t) has a continuous derivative v(t), then:

    s = lim(n→∞, max Δtᵢ→0) sₙ = integral(a to b) |dr/dt| dt = integral(a to b) |v(t)| dt = integral(a to b) v(t) dt

In kinematic terms, this formula states that the distance travelled by a moving particle is the integral of its speed.


[sid 647]

Remark Although the above formula is expressed in terms of the parameter t, the arc length, as defined above, is a strictly geometric property of the curve C. It is independent of the particular parametrization used to represent C. See Exercise 27 at the end of this section.

If s(t) denotes the arc length of that part of C corresponding to parameter values in [a, t], then:

    ds/dt = d/dt [integral(a to t) v(τ) dτ] = v(t)

so that the arc length element for C is given by:

    ds = v(t) dt = |dr/dt| dt

The length of C is the integral of these arc length elements; we write:

    integral_C ds = length of C = integral(a to b) v(t) dt

Several familiar formulas for arc length follow from the above formula by using specific parametrizations of curves. For instance, the arc length element ds for the Cartesian plane curve y = f(x) on [a, b] is obtained by using x as parameter; here, r = xi + f(x)j, so v = i + f'(x)j and:

    ds = sqrt(1 + (f'(x))^2) dx

Similarly, the arc length element ds for a plane polar curve r = g(θ) can be calculated from the parametrization:

    r(θ) = g(θ) cos θ i + g(θ) sin θ j

It is:

    ds = sqrt((g(θ))^2 + (g'(θ))^2) dθ

## EXAMPLE 6

Find the length s of that part of the circular helix:

    r = a cos t i + a sin t j + bt k

between the points (a, 0, 0) and (a, 0, 2πb).

Solution This curve spirals around the z-axis, rising as it turns. It lies on the surface of the circular cylinder x^2 + y^2 = a^2. We have:

    v = dr/dt = -a sin t i + a cos t j + bk
    v = sqrt(a^2 + b^2)

so that in terms of the parameter t the helix is traced out at constant speed. The required length s corresponds to parameter interval [0, 2π]. Thus:

    s = integral(0 to 2π) v(t) dt = integral(0 to 2π) sqrt(a^2 + b^2) dt = 2π sqrt(a^2 + b^2)

### Piecewise Smooth Curves

As observed earlier, a parametric curve C given by r = r(t) can fail to be smooth at points where dr/dt = 0. If there are finitely many such points, we will say that the curve is piecewise smooth.

In general, a piecewise smooth curve C consists of a finite number of smooth arcs, C₁, C₂, ..., Cₖ.

[FIGUR 12.13: En piecewise smooth kurva]

In this case we express C as the sum of the individual arcs:

    C = C₁ + C₂ + ... + Cₖ

Each arc Cᵢ can have its own parametrization:

    r = rᵢ(t),  (aᵢ ≤ t ≤ bᵢ)

where vᵢ = drᵢ/dt ≠ 0 for aᵢ < t < bᵢ. The fact that Cᵢ₊₁ must begin at the point where Cᵢ ends requires the conditions:

    rᵢ₊₁(aᵢ₊₁) = rᵢ(bᵢ)  for 1 ≤ i ≤ k - 1

If also rₖ(bₖ) = r₁(a₁), then C is a closed piecewise smooth curve.

The length of a piecewise smooth curve C = C₁ + C₂ + ... + Cₖ is the sum of the lengths of its component arcs:

    length of C = sum(i=1 to k) integral(aᵢ to bᵢ) |drᵢ/dt| dt

### The Arc-Length Parametrization

The selection of a particular parameter in terms of which to specify a given curve will usually depend on the problem in which the curve arises; there is no one "right" way to parametrize a curve. However, there is one parameter that is "natural" in that it arises from the geometry (shape and size) of the curve itself and not from any particular coordinate system in which the equation of the curve is to be expressed. This parameter is the arc length measured from some particular point (the initial point) on the curve. The position vector of an arbitrary point P on the curve can be specified as a function of the arc length s along the curve from the initial point P₀ to P;

    r = r(s)

This equation is called an arc-length parametrization or intrinsic parametrization of the curve. Since ds = v(t) dt for any parametrization r = r(t), for the arc-length parametrization we have ds = v(s) ds. Thus, v(s) = 1, identically; a curve parametrized in terms of arc length is traced at unit speed. Although it is seldom easy (and usually not possible) to find r(s) explicitly when the curve is given in terms of some other parameter, smooth curves always have such parametrizations, and they will prove useful when we develop the fundamentals of the differential geometry for 3-space curves in the next section.


[sid 649]

Suppose that a curve is specified in terms of an arbitrary parameter t. If the arc length over a parameter interval [t₀, t]:

    s = s(t) = integral(t₀ to t) |dr(τ)/dτ| dτ

can be evaluated explicitly, and if the equation s = s(t) can be explicitly solved for t as a function of s (t = t(s)), then the curve can be reparametrized in terms of arc length by substituting for t in the original parametrization:

    r = r(t(s))

## EXAMPLE 7

Parametrize the circular helix:

    r = a cos t i + a sin t j + btk

in terms of the arc length measured from the point (a, 0, 0) in the direction of increasing t.

Solution The initial point corresponds to t = 0. As shown in Example 6, we have:

    ds/dt = sqrt(a^2 + b^2)

so:

    s = s(t) = integral(0 to t) sqrt(a^2 + b^2) dτ = sqrt(a^2 + b^2) t

Therefore, t = s / sqrt(a^2 + b^2), and the arc-length parametrization is:

    r(s) = a cos(s / sqrt(a^2 + b^2)) i + a sin(s / sqrt(a^2 + b^2)) j + (bs) / sqrt(a^2 + b^2) k
