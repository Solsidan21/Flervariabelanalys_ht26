### Uppgift 1
(a) Let f : R^2 -> R be a function. Explain the difference between f having two partial derivatives at a point (x_0, y_0), and the function being differentiable at (x_0, y_0). (2p)
(b) If f is C^2 and there exists a C^2-function g such that partial f/partial x = partial g/partial y and partial f/partial y = -partial g/partial x, show that f fulfills

    partial^2 f/partial x^2 + partial^2 f/partial y^2 = 0.  (2p)

(c) Show that f(x, y) = arctan(y/x) is a function that satisfies the above equation off the x-axis. (2p)

### Uppgift 2
(a) Find the equation for the tangent plane of the function in 1(c) at the point (x, y) = (2, 2). (2p)
(b) What is the normal vector to the plane in (a)? (1p)
(c) At the point (1, -1, 2), in what direction is the function f(x, y, z) = x/||(x, y, z)|| increasing the most? (2p)

### Uppgift 3
Consider the function f(x, y) = 3x^2 - 4xy + y^2. Show that the origin is a critical point and determine whether it is a local max, min or a saddle point. (3p)

### Uppgift 4
Compute the integrals over the given regions, and sketch the region in question:
(a) doubleintegral over D x dA where D = {(x, y) : 1 <= x <= 2, x^2 <= y <= x^3}. (2p)
(b) doubleintegral over D 1/(x + y) dA where D = {(x, y) : 1 <= y <= 2, 0 <= x <= y}. (2p)
(c) doubleintegral over D e^(x^2 + y^2) dA where D = {(x, y) : x^2 + y^2 <= 2}. (2p)

### Uppgift 5
Show that the equation x + y + z + cos(xyz) = 0 locally defines z as a function phi of (x, y) near the point (0, 0, -1). Also compute the derivatives partial phi/partial x (0, 0) and partial phi/partial y (0, 0). (4p)

### Uppgift 6
(a) Find the maximum and the minimum of the function

    f(x, y) = xy sqrt(1 - x^2 - y^2)

in the unit disc. (3p)
(b) Find the maximum and the minimum of the function

    f(x, y) = x^3 y^2 (1 - x - y)

in the first quadrant of the plane R^2, i.e. {(x, y) : x >= 0, y >= 0}. (3p)
